# Coerce lists and character vectors to scopes

`as_scopes()` turns an existing object into a `scopes`. This is in
contrast with
[`class_scopes()`](https://rapid.api2r.org/reference/class_scopes.md),
which builds a `scopes` from individual properties.

## Usage

``` r
as_scopes(x, ...)
```

## Arguments

- x:

  The object to coerce. Must be coercible to a named character vector.

- ...:

  These dots are for future extensions and must be empty.

## Value

A `scopes` as returned by
[`class_scopes()`](https://rapid.api2r.org/reference/class_scopes.md).
