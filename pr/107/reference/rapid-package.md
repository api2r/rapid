# rapid: R 'API' Descriptions

Convert an 'API' description ('APID'), such as one that follows the
'OpenAPI Specification', to an R 'API' description object (a "rapid").
The rapid object follows the 'OpenAPI Specification' to make it easy to
convert to and from 'API' documents.
